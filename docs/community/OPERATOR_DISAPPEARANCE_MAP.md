## Release evidence still missing

For a selected deployment, retain chain IDs, contract addresses and runtime hashes, configuration/creation receipts, service/data inventory, required public bytes, separate acquisition operators, exact key roles (never secrets), and successful/failed recovery receipts. A code-level path is not evidence of current deployed state. Chain consensus/finality, transport delivery and availability cannot be certified from these source files.

Run one loss scenario at a time on an authorized disposable environment. Record the exact operation that stops, whether it can be resumed with another operator's resources, and any persistent authority or missing bytes. Do not introduce a developer reset key to make a scenario pass. Preserve failed evidence.

The source/discussion archive r18 has an independently restored 421 PR heads; it does not contain all remote dependencies, live databases, user secrets, attachments or full proving/runtime recovery. A private archive is also not public availability proof. The map's relevant PRs are proposals, not accepted fixes or evidence their combination works.
